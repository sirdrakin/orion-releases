# Orion Gestão Empresarial

Repositório oficial de **distribuição e atualizações** do Orion para Windows 64 bits.

## Download

- [Última versão estável](https://github.com/sirdrakin/orion-releases/releases/latest)
- [Todas as versões, inclusive testes](https://github.com/sirdrakin/orion-releases/releases)

Em **Assets**, baixe o arquivo `Orion-Instalador-vX.Y.Z.exe`. As versões marcadas **Pre-release** são destinadas a testes e não são oferecidas pelo atualizador estável.

## Instalação e configuração

- [Guia de instalação individual e em rede](docs/guia-instalacao.md)
- [Novidades da versão 2.3.1](docs/NOTAS-v2.3.1.md)

**Importante:** o modo rede da 2.3.1 ainda depende de validação prática com dois computadores Windows. Antes de atualizar, faça backup dos dados pelo próprio Orion.

Este repositório contém somente arquivos públicos de distribuição e documentação. O código-fonte privado do aplicativo e os dados financeiros dos clientes não são publicados aqui.
